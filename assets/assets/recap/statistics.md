# Statistics

## 1. Statistical Concepts

| Concept | Description |
| --- | --- |
| Statistical Sampling | Selecting a representative subset of a population |
| Mean | Average value |
| Median | Middle value |
| Mode | Most frequent value |

## 2. Data Distribution

| Type | Description |
| --- | --- |
| Normal Distribution | Bell curve and symmetric |
| Left-Skewed | Tail extends to the left |
| Right-Skewed | Tail extends to the right |

## 3. Variability and Probability

| Concept | Description |
| --- | --- |
| Probability | Likelihood of events based on past data |
| Variance | Measures spread of data from the mean |
| Standard Deviation | Square root of variance and shows consistency |
| Outliers | Extreme values that differ significantly |

# Natural Language Processing

## 1. What is NLP?

- NLP is the branch of AI that helps computers understand and respond to human language.
- Natural language is how humans communicate.
- Processing means analyzing language for machines.

## 2. Five Stages of NLP

| Stage | Function |
| --- | --- |
| Lexical Analysis | Breaks text into words or phrases |
| Syntactic Analysis | Checks grammar structure |
| Semantic Analysis | Understands meaning |
| Discourse Integration | Understands context across sentences |
| Pragmatic Analysis | Interprets intent and purpose |

## 3. Text Processing Steps

| Step | Description |
| --- | --- |
| Sentence Segmentation | Split text into sentences |
| Tokenization | Split sentences into words or tokens |
| Stop Word Removal | Remove common words like the, is, and |
| Case Conversion | Convert text to lowercase |

## 4. Word Reduction

| Technique | Description |
| --- | --- |
| Stemming | Reduces words to a root form and may lose meaning |
| Lemmatization | Reduces words to a base form while preserving meaning |

## 5. Converting Text to Numbers

| Method | Description |
| --- | --- |
| Bag of Words | Counts word frequencies in documents |
| TF-IDF | Gives more importance to unique and meaningful words |

## 6. NLP Tools

| Code-Based | No-Code |
| --- | --- |
| NLTK | MonkeyLearn |
| SpaCy | Orange Data Mining |

## 7. NLP Applications and Chatbots

- Chatbots can be rule-based script bots or AI-powered smart bots.
- Common applications: voice assistants, captions, translation, sentiment analysis, and keyword extraction.

# Computer Vision

## 1. What is Computer Vision?

- Computer vision enables machines to see, analyze, and understand images and videos.
- It mimics human vision by capturing, processing, and recognizing visual data.

## 2. Image Basics

| Concept | Description |
| --- | --- |
| Pixel | Smallest unit of an image |
| Resolution | Higher resolution gives clearer images |
| Grayscale | Values range from 0 black to 255 white |
| RGB | Red, green, and blue channels combine for color |

## 3. Key Computer Vision Tasks

- Image classification asks what is in the image.
- Object detection asks where objects are located.
- Instance segmentation identifies pixel-level object boundaries.

## 4. Feature Extraction

- Feature extraction detects edges, corners, and patterns in images.
- Convolution uses small filters or kernels to highlight important features.

## 5. Applications

- Facial recognition
- Medical imaging
- Self-driving cars
- AR filters such as Snapchat and Instagram effects

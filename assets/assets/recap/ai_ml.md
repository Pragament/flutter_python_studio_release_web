# AI and Machine Learning

## 1. Core Concepts

| Concept | Description |
| --- | --- |
| AI | Uses data to learn patterns and make predictions |
| Features | Characteristics that help classify objects |
| Labels | Correct answers the model learns to predict |
| Training Data | Used for learning patterns |
| Testing Data | Used to check accuracy |

## 2. AI Approaches

| Approach | Description |
| --- | --- |
| Rule-Based | Follows fixed rules and does not improve on its own |
| Learning-Based | Learns from data and improves with experience |

## 3. Types of Machine Learning

| Type | Description | Examples |
| --- | --- | --- |
| Supervised Learning | Uses labeled data | Classification, regression |
| Unsupervised Learning | Finds patterns in unlabeled data | Clustering, association |
| Reinforcement Learning | Learns through rewards and penalties | Game AI, robotics |

## 4. Deep Learning

- Processes large datasets and recognizes complex patterns.
- Artificial neural networks mimic part of the human brain structure.

## 5. Neural Network Components

| Component | Function |
| --- | --- |
| Input Layer | Receives raw data |
| Hidden Layers | Process and transform data |
| Weights and Biases | Adjust feature importance |
| Activation Function | Filters unnecessary details |
| Perceptron | Combines inputs, weights, bias, and threshold |

## 6. Convolutional Neural Networks

- CNNs specialize in image processing.
- Common uses include facial recognition and object detection.

| CNN Layer | Function |
| --- | --- |
| Convolution Layer | Detects features using filters or kernels |
| ReLU Layer | Removes negative values |
| Pooling Layer | Reduces size while keeping important features |
| Fully Connected Layer | Classifies the image |
